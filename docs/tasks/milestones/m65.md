# Milestone 65 — Traversal Directionality & Interaction Cleanup

**Goal:** Fix traversal bugs reported during playtest after edge-based movement changes.

**Status:** ✅ COMPLETED

## Bugs Addressed

1. Wrong-direction edge transitions (north push could take west exit).
2. Room travel transitions not consistently consuming a turn.
3. First-room redundant interaction points (`n` and adjacent `!` opening same dialog).

## Scope Delivered

- Added directional mapping for edge transitions using travel-trigger orientation.
- Made travel-trigger and edge-transition room moves spend a world turn.
- Removed redundant dialog triggers from `ash_gate` so NPC interaction points are not duplicated.
- Added flow tests for directionality and turn-consumption behavior.
- Updated visual scenario expectation to match corrected movement behavior.

**Done when:**
- [x] Edge pushes only transition via direction-matching room links.
- [x] Room travel transitions advance turn state.
- [x] First-room dialog interaction redundancy is removed.
- [x] `cargo test` and visual scenarios pass.
