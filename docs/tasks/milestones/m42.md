# M42 — Visual Regression Testing

**Status:** ✅ completed
**Depends on:** M41

---

## Goal

Enable the agent to capture rendered frames and detect visual regressions, ensuring UI changes don't break existing screens.

---

## Scope

- **Frame Capture**: Extract the rendered frame as a text/ANSI buffer.
- **Baseline Storage**: Store expected outputs for each screen in `tests/baselines/`.
- **Diff Engine**: Compare current output against baseline and report differences.
- **Auto-Update**: Flag when baselines need updating vs when regressions occur.

---

## Target Files

- `src/app/visual_testing.rs` (New): Visual regression testing engine.
- `src/app/testing.rs`: Headless testing with snapshot support.

---

## Done When

- [x] All main screens have baseline captures.
- [x] Visual diffs are reported with line/column context.
- [x] CI runs visual regression tests automatically.
