# M41 — Headless Integration Testing Framework

**Status:** 🔲 planned
**Depends on:** M40

---

## Goal

Create a framework for the agent to run the game in headless mode and verify game state changes, allowing pixel-free verification of gameplay mechanics.

---

## Scope

- **Headless Renderer**: Implement a `HeadlessRenderer` that captures game state without rendering to a terminal.
- **State Snapshots**: Capture and compare game state at any point (player position, HP, inventory, quest state).
- **Action Replay**: Record and replay player actions to verify deterministic behavior.
- **Integration Tests**: Convert existing gameplay scenarios into headless test cases.

---

## Target Files

- `src/renderer/headless.rs` (New): Headless renderer implementation.
- `src/app/testing.rs` (New): Testing utilities for state inspection.
- `tests/integration/`: Integration test scenarios.

---

## Done When

- [ ] Agent can run game scenarios without terminal.
- [ ] Game state can be queried and verified programmatically.
- [ ] At least 5 core gameplay scenarios run in headless mode.
