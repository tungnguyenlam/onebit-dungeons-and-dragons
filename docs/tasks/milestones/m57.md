# Milestone 57 — Crafting & Alchemy Systems

**Goal:** Add a new layer of character progression by allowing players to utilize monster drops and environmental resources to create powerful consumables and gear.

**Design:**
1. **Ingredient Property:** Add `is_ingredient` and `crafting_tags` to `ItemDef`.
2. **Recipe Registry:** Create `assets/recipes/` to define combinations (e.g., 2x Spider Silk + Leather = Reinforced Boots).
3. **Alchemy UI:** Add a new TUI screen (`Alchemy`) accessible via NPCs or specific furniture (Alchemist's Bench).
4. **Harvesting Mechanic:** Implement 5e-style "Survival" checks after combat to harvest components from certain monsters (e.g., Dragon Scales, Poison sacs).

**Files to create/modify:**
- `src/data/types.rs` (update `ItemDef`, add `RecipeDef`)
- `src/game/items/mod.rs` (crafting logic)
- `src/ui/tui/screens/crafting.rs` (new UI screen)
- `src/app/actions.rs` (add "Harvest" action)

**Done when:**
- [ ] Items can be tagged as ingredients in TOML.
- [ ] Players can combine ingredients to produce a new item via the recipe UI.
- [ ] Successful Survival checks after combat award crafting components.
- [ ] At least 5 recipes (3 Potions, 2 Gear upgrades) are functional.
