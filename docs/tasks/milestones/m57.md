# Milestone 57 — Crafting & Alchemy Systems

**Goal:** Add a new layer of character progression by allowing players to utilize monster drops and environmental resources to create powerful consumables and gear.

**Status:** ✅ COMPLETED

**Design:**
1. **Ingredient Property:** Added `is_ingredient` and `crafting_tags` to `ItemDef`.
2. **Recipe Registry:** Created `assets/recipes/` with 5 recipes (greater healing potion, antivenom, elixir of heroism, reinforced boots, dragon scale shield).
3. **Alchemy UI:** Added a new TUI screen (`Crafting`) accessible via 'c' key in world map.
4. **Harvesting Mechanic:** Added `harvest_from_monster` function in actions.rs for harvesting components after combat (framework in place, needs integration).
