# M25 — Faction Simulation Expansion

**Status:** 🔲 next  
**Depends on:** M22 (Quest Runtime), M23 (Combat AI)

---

## Goal

Expand faction reputation from a passive WorldState counter into an active
simulation layer: NPCs react differently based on live rep score; rep changes
fire observable world events; factions have inter-faction relationships.

---

## Scope

- Reputation deltas only; no new UI screens
- Covers: hostile-on-sight threshold, dialog unlock gates, faction war events
- Non-goal: full diplomatic negotiation system

---

## Target Files

- `src/game/story/world_state.rs` — faction helper methods
- `src/game/story/events.rs` — faction-threshold event triggers
- `src/app.rs` — route faction events to AI + combat + dialog
- `assets/regions/*/npcs/*.toml` — add `faction_id` where missing
- `docs/gameplay/npc-ai.md` — update with faction rep integration

---

## Done When

- [ ] `WorldState::faction_rep(id)` / `modify_faction_rep(id, delta)` helpers exist
- [ ] NPCs with rep below `hostile_threshold` auto-initiate combat on room entry
- [ ] Rep changes ≥ ±5 emit journal entries (World category)
- [ ] At least one inter-faction event: if rep A < -5 while rep B > 5, faction B becomes actively friendly (dialog unlock)
- [ ] Tests: hostile-threshold combat trigger, rep-change journal entry, inter-faction unlock

---

## Verification

```bash
cargo test faction -- --nocapture
cargo run -- --validate-assets
```

---

## Risks

- Hostile-on-sight logic must not trigger during dialog state → guard in `App::dispatch`
- Rep deltas from combat outcomes (XP kill) must not double-count
