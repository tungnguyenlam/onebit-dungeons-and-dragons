# M30 — World Map Structure Update

**Status:** 🔲 planned
**Depends on:** M29 (v0.2.0 Release Gate)

---

## Goal

Transition from isolated region instances to a cohesive, interconnected world map structure. Establish the architectural foundation for seamless travel between distinct regions (e.g., from Valley of Ash to upcoming areas).

---

## Scope

- **Overworld Navigation**: Define connecting "border rooms" or transition points that load adjacent regions.
- **Region Memory**: Ensure region state (NPCs, triggered events) is preserved accurately when the player moves between regions.
- **UI Scaling**: Update the World Map HUD to handle cross-region breadcrumbs or a zoomed-out macro map view.

---

## Target Files

- `src/game/world/region.rs`: Logic for transitioning regions.
- `src/app.rs`: State persistence across region boundaries.
- `assets/regions/`: Modify transition triggers to handle external region slugs.

---

## Done When

- [ ] Region transition triggers can successfully load a separate region TOML.
- [ ] Save format retains changes made in non-active regions.
- [ ] `cargo test` passes.
