# M49 — Settings & Accessibility Panel

**Status:** ✅ completed
**Depends on:** M44

---

## Goal

Create a comprehensive settings screen with accessibility options, control customization, and visual preference controls.

---

## Scope

- **Display Settings**: Theme, font size, animation toggle.
- **Accessibility**: Color blind modes, reduced motion, screen reader hints.
- **Controls**: Remap movement and action keys.
- **Sound Settings**: Volume, mute toggles.
- **Save/Load**: Manual save/load controls.
- **Advanced**: Debug mode, log viewing.

---

## Target Files

- Settings already in state.rs with SettingsConfig.
- Environment variable support: DND_THEME, DND_REDUCED_MOTION, DND_COLOR_BLIND.
- Audio engine supports DND_SOUND, DND_VOLUME_* env vars.

---

## Done When

- [x] All settings persist across sessions.
- [x] Accessibility modes are toggleable.
- [x] Controls can be customized.
- [x] Settings screen is navigable via keyboard only.
