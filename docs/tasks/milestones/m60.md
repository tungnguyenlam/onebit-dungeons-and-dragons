# Milestone 60 — Final Boss, Ending Variations & New Game+

**Goal:** Implement the narrative and mechanical conclusion of the game, including the climactic confrontation and the ability to restart with certain unlocks.

**Design:**
1. **Final Boss Logic:** Create a multi-phase boss encounter for the Underdark Shelf (The Void Architect or equivalent).
2. **Narrative Endings:** Implement a system in `src/game/story/mod.rs` to calculate an "Ending Score" based on WorldState flags (e.g., bandit_king_alive, factions_allied) and display one of several ending cinematic scrolls.
3. **New Game+:** Allow players who complete the game to start a new journey with retained levels, unique "Inherited Feats", or increased enemy difficulty scaling.
4. **Credits Screen:** Add a scrolling credits screen to the TUI.

**Files to modify:**
- `src/game/story/mod.rs` (ending calculation logic)
- `src/ui/tui/screens/ending.rs` (new screen for ending/credits)
- `src/app/mod.rs` (handle game restart/NG+ state)
- `assets/monsters/boss.toml` (stat block for final encounter)

**Done when:**
- [ ] Defeating the final boss triggers the ending sequence.
- [ ] Different endings are presented based on previous story choices.
- [ ] Credits roll correctly.
- [ ] Players can trigger a New Game+ from the main menu after a successful completion.
