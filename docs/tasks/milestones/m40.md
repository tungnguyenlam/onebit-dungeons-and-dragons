# M40 — Retained-Mode VFX Engine

**Status:** 🔲 planned
**Depends on:** M39

---

## Goal

Elevate the TUI presentation by fully utilizing modern terminal retained-mode rendering (Truecolor, fast update rates). Introduce a central Animation and Visual Effects (VFX) engine that overlays graphical effects securely over the base game state, degrading gracefully to T0 (ASCII) or low-update rates.

---

## Scope

- **High-Frequency Update Loop**: Increase base renderer polling loop from 250ms (Tick) to ~33ms (30 FPS) while ensuring input handling stays snappy.
- **VFX State Machine**: Create a `VfxEngine` attached to `App` (or strictly in the UI layer) to track ephemeral animations (position, color gradients, lifetimes) without polluting pure game data.
- **Effect Primitives**:
    - **Damage Floaters**: Text (e.g., `-12!`) that spawns at a map coordinate and drifts upward, fading out using Truecolor alpha-blending logic.
    - **Tile Pulses**: Soft sine-wave opacity/color pulsing for hovered tiles, exits, or active targets.
    - **Screen Wipes**: Transition animations when moving between regions or changing major screens (e.g., dissolving block characters).
- **Capability Degradation**: Ensure that if `ThemeTier` is `T0` or `T1`, or `reduced_motion = true`, animations are instantly skipped or converted to static high-contrast markers.

---

## Target Files

- `src/renderer.rs`: Adjust `GameEvent::Tick` rate or split it into `Frame` and `LogicTick`.
- `src/ui/tui/vfx.rs` (New): Data structures for tracking active animations.
- `src/ui/tui/screens/world_map.rs`: Integrating overlay text and tile coloring over the standard grid render.
- `src/ui/tui/theme.rs`: Color lerping (linear interpolation) functions for gradients.

---

## Done When

- [ ] Baseline FPS can run at 30 without exceeding CPU budgets.
- [ ] At least one floating combat text appears when damage is dealt.
- [ ] At least one tile pulse effect is applied to an interactive object.
- [ ] Setting `DND_REDUCED_MOTION=1` disables the effects cleanly.
