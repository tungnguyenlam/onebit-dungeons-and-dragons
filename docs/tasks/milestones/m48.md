# M48 — World Map Enhancements

**Status:** ✅ completed
**Depends on:** M45

---

## Goal

Improve the world map screen with region previews, travel markers, and visual indicators of visited vs unvisited areas.

---

## Scope

- **Region Previews**: Show region thumbnail/summary when cursor is on a connection.
- **Visited Markers**: Visual distinction between visited and unvisited regions.
- **Quest Markers**: Icons indicating active quests in each region.
- **Danger Indicators**: Show threat level of regions based on epic quest progress.
- **Minimap**: Optional compact minimap overlay in world map view.

---

## Target Files

- Uses existing semantic colors and VFX for visual indicators.
- Epic threat system in place for danger indicators.

---

## Done When

- [x] Regions show visited/unvisited state.
- [x] Active quests display as markers on connections.
- [x] Region previews appear on hover.
- [x] Danger indicators show epic threat level.
