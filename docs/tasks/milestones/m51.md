# M51 — Step-Through Testing Tool Fix

**Status:** 🟡 in_progress
**Depends on:** None

---

## Goal

Fix the step-through testing tool so that state persists between steps, allowing agents to test gameplay mechanics (movement, combat, inventory) properly.

---

## Problem

Currently, `scripts/runtest.sh` creates a **new game** every time it's run. This means:
- Player starts fresh at position (3,2) each time
- Can't test movement across multiple steps
- Can't test combat encounters
- Can't test inventory management properly

---

## Scope

### Required Fixes

1. **State Persistence**
   - Make `scripts/runtest.sh` preserve game state between runs
   - Use save/load mechanism, OR
   - Store state in a file that loads on startup

2. **Test Scenarios**
   - Character creation flow works
   - Movement works (up/down/left/right)
   - Inventory open/close works
   - Combat encounter can be triggered
   - Combat actions (attack/wait) work
   - Monster can be defeated
   - Loot/XP is awarded after combat

3. **Optional Improvements**
   - Scenario scripts (e.g., `scripts/test_combat.sh`)
   - Automated test assertions

---

## Target Files

- `scripts/runtest.sh` - Main testing script
- `src/main.rs` - May need changes to support state persistence
- `src/app/mod.rs` - dump_state function

---

## Done When

- [ ] Running `scripts/runtest.sh j` then `scripts/runtest.sh j` shows player moved twice
- [ ] Can navigate from spawn to encounter trigger
- [ ] Can trigger and complete a combat encounter
- [ ] Inventory can be opened and items seen
- [ ] Combat rewards (XP, gold) are displayed after winning
- [ ] Documentation updated in `docs/testing/step-through-testing.md`

---

## Example Usage After Fix

```bash
# Start game
scripts/runtest.sh

# Create character (navigate through menus)
scripts/runtest.sh $'\r'  # Enter: New Game
scripts/runtest.sh j       # Select fighter
scripts/runtest.sh $'\r'  # Confirm
scripts/runtest.sh j       # Select human
scripts/runtest.sh $'\r'  # Confirm

# Move around in world
scripts/runtest.sh j       # move down
scripts/runtest.sh l       # move right

# Open inventory
scripts/runtest.sh i       # inventory

# Find and fight monster
scripts/runtest.sh ...     # navigate to encounter
scripts/runtest.sh a       # attack
```
