# Milestone 67 — World Gen Foundation & Seeded Runtime

**Goal:** Introduce deterministic map generation core and seed pipeline.

**Status:** 🔲 PLANNED

## Scope
- Add `src/game/world/generation/` modules:
  - `seed.rs` (world seed + per-region derivation)
  - `layout.rs` (room graph generation)
  - `tiles.rs` (biome tile painting)
  - `validate.rs` (connectivity/constraint checks)
- Add save support for world seed + generated region ids.
- Add runtime mode toggle (`fixed_only`, `hybrid`, `generated_only` for dev/testing).

## Data Contracts
- `GeneratedRegionSpec`: biome, danger tier, room bounds, landmark policy.
- `GeneratedRoomSpec`: shape, hazard budget, encounter budget.

## Done when
- [ ] Same seed always yields same generated layout/content.
- [ ] Connectivity guarantees validated (entry to required nodes reachable).
- [ ] Generator snapshot tests exist and pass.
