# Milestone 68 — Hybrid Region Router (Fixed Hubs + Generated Routes)

**Goal:** Route travel between authored hubs and generated exploration regions.

**Status:** 🔲 PLANNED

## Scope
- Keep hubs authored (castle, traveler association, blacksmith districts).
- Add generated connector routes (`road`, `wild`, `cave`) between hub regions.
- Update travel system for:
  - fixed -> generated
  - generated -> fixed
  - generated -> generated chains
- Add generated-region lifecycle manager (create/cache/evict safely).

## Done when
- [ ] Player can traverse hub -> generated -> hub reliably.
- [ ] Save/load restores generated route state and player position.
- [ ] No broken transitions between fixed and generated regions.
