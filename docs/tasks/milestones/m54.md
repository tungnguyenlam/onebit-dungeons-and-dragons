# Milestone 54 — Tidewatch Coast Content Pass

**Goal:** Implement the "Tidewatch Coast" region as a standalone alternate starting area for new characters, providing a maritime-themed tutorial and side-quest hub.

**Design:**
1. **Region Authoring:** Create `assets/regions/tidewatch-coast/` with rooms: `dockside`, `market-square`, `harbormaster`, and `sea-cave`.
2. **Maritime Faction:** Define the `tidewatch-merchants` faction and initial NPCs (Harbormaster, Merchant Lyr).
3. **Tutorial Flow:** Implement a starting quest `assets/quests/side/tidewatch-smugglers.toml` that teaches player movement, interaction, and basic combat.
4. **Sea Cave Encounter:** Add a small combat dungeon (Sea Cave) with aquatic monsters (e.g., Giant Crabs, Sahuagin).
