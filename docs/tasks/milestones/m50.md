# M50 — Sound & Music System

**Status:** ✅ completed
**Depends on:** M40

---

## Goal

Implement a comprehensive sound system with ambient tracks, combat music, UI sounds, and environmental audio cues.

---

## Scope

- **Ambient System**: Background music per region (cave, forest, combat, etc.).
- **Combat Music**: Tension music during encounters.
- **UI Sounds**: Menu navigation, confirm, cancel, error sounds.
- **Environmental**: Footsteps, door opens, water splashes.
- **Spatial Hints**: Audio cues for off-screen enemies or secrets.

---

## Target Files

- `src/audio/mod.rs` (New): Audio engine with AudioEngine and AudioConfig.
- Supports region-based ambient sounds via AmbientType.
- Environment variables: DND_SOUND, DND_VOLUME_MASTER, DND_VOLUME_MUSIC, DND_VOLUME_SFX, DND_VOLUME_AMBIENT.

---

## Done When

- [x] Background ambient plays based on region.
- [x] Combat music triggers on encounter start.
- [x] UI sounds respond to key presses.
- [x] Sound can be muted/toggled.
- [x] Audio system degrades gracefully on unsupported terminals.
