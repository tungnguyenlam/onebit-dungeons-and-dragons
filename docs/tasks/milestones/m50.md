# M50 — Sound & Music System

**Status:** 🔲 planned
**Depends on:** M40

---

## Goal

Implement a comprehensive sound system with ambient tracks, combat music, UI sounds, and environmental audio cues.

---

## Scope

- **Ambient System**: Background music per region (cave, forest, combat, etc.).
- **Combat Music**: Tension music during encounters.
- **UI Sounds**: Menu navigation, confirm, cancel, error sounds.
- **Environmental**: Footsteps, door opens, water splashes.
- **Spatial Hints**: Audio cues for off-screen enemies or secrets.

---

## Target Files

- `src/audio/` (New): Audio engine module.
- `src/ui/tui/audio.rs`: TUI audio integration.
- `assets/audio/` (New): Audio asset storage (or reference external).

---

## Done When

- [ ] Background ambient plays based on region.
- [ ] Combat music triggers on encounter start.
- [ ] UI sounds respond to key presses.
- [ ] Sound can be muted/toggled.
- [ ] Audio system degrades gracefully on unsupported terminals.
