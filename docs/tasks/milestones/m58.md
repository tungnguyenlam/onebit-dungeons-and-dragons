# Milestone 58 — Bestiary & Shared Lore UI

**Goal:** Enhance the "completionist" aspect of the game by providing a dedicated interface to view discovered monster stats and lore logs.

**Design:**
1. **Discovery Tracker:** Add `discovered_monsters` and `discovered_lore` sets to `WorldState`.
2. **Bestiary Screen:** A TUI screen listing every unique monster defeated, showing their HP, AC, Resistances, and a short description.
3. **Lore Library:** A categorized view of all environmental lore strings collected from rooms or quest items.
4. **Knowledge Bonus:** (Optional) Grant a small combat bonus (e.g., +1 to hit) against monsters once their Bestiary entry is "fully researched" (e.g., after 5 kills).

**Files to create/modify:**
- `src/game/story/mod.rs` (track discoveries)
- `src/ui/tui/screens/bestiary.rs` (new UI screen)
- `src/ui/tui/screens/lore_library.rs` (new UI screen)
- `src/app/handlers.rs` (bind key to open Bestiary)

**Done when:**
- [ ] Defeating a new monster adds it to the Bestiary.
- [ ] Inspecting lore-tagged objects adds entries to the Lore Library.
- [ ] Bestiary displays accurate stat blocks for discovered entities.
- [ ] Both screens are accessible from the Journal or Main Menu.
