# M47 — Combat UI Overhaul

**Status:** 🔲 planned
**Depends on:** M45

---

## Goal

Redesign the combat interface for better readability, faster decision-making, and visual clarity during encounters.

---

## Scope

- **Action Panel**: Clear display of available actions with hotkey hints.
- **Enemy Framing**: Highlight selected enemy with border/background.
- **Combat Log**: Styled log with color-coded damage types and critical hits.
- **Timeline Viz**: Visual turn order with current actor highlighted.
- **Damage Numbers**: Integrate VFX damage floaters into combat view.

---

## Target Files

- `src/ui/tui/screens/combat.rs`: Redesigned combat screen.
- `src/ui/tui/widgets/combat.rs`: Combat-specific widgets.

---

## Done When

- [ ] Action panel shows all available actions with hotkeys.
- [ ] Selected enemy is clearly highlighted.
- [ ] Combat log shows last 10 events with color coding.
- [ ] Turn order timeline is visible.
