# Milestone 61 — Map Widgets & World Map Utility

**Goal:** Create reusable map widgets and a utility layer that presents region/world-map information in a structured way for TUI screens.

**Status:** ✅ COMPLETED

**Design:**
1. **World Map Utility:** Build a utility that converts runtime region data into render-ready overview objects (rooms, current room, exits, lock state).
2. **Reusable Widgets:** Add map-focused widgets for room list and exit list so screens can reuse formatting/visual behavior.
3. **World Map Screen Integration:** Replace ad-hoc right-panel text with widget-based world map information while preserving local tile map rendering.
4. **Validation:** Add tests for utility/widget output and verify with headless visual dumps.

- `src/app/navigation/world_map_util.rs` (new)

- `src/ui/tui/widgets/map.rs` (new)

- `src/ui/tui/screens/world_map.rs`
