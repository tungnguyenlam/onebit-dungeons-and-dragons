# M28 — Difficulty & Accessibility Settings

**Status:** 🔲 planned
**Depends on:** M27

---

## Goal

Provide a new Settings menu allowing the player to adjust the game's difficulty modifiers and accessibility options (e.g. reduced motion).

---

## Scope

- **Settings Menu**: Expand `AppState` and UI to include a Settings screen holding game configurations.
- **Difficulty modifiers**: Add `enemy_hp_multiplier` and `player_damage_multiplier` settings.
- **Accessibility**: Provide an in-game toggle for the existing `reduced_motion` visual config so players don't need environment variables.

---

## Target Files

- `src/app.rs`: State for Settings.
- `src/ui/tui/screens/` : Add `settings.rs`.
- `src/ui/tui/mod.rs` : Add support for toggling.
- `src/game/combat/`: Factor in modifiers.

---

## Done When

- [ ] Settings enum handles standard toggles/multipliers.
- [ ] Setting screen is accessible from the Main Menu or pause.
- [ ] Combat equations respect the selected difficulty.
