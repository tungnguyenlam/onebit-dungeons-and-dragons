# M45 — Animated UI Elements

**Status:** 🔲 planned
**Depends on:** M44

---

## Goal

Add smooth animations to UI elements using the VFX engine, making the interface feel more alive and responsive.

---

## Scope

- **Menu Animations**: Animated main menu with title effects.
- **HP/MP Bars**: Smooth interpolation when health/mana changes.
- **Screen Transitions**: Fade and slide effects between screens.
- **Cursor Effects**: Blinking/breathing cursor on interactive elements.
- **Particle Effects**: Simple ASCII particle effects for combat impacts.

---

## Target Files

- `src/ui/tui/vfx.rs`: Extended with UI animations.
- `src/ui/tui/screens/`: Update screens with animation calls.

---

## Done When

- [ ] Main menu has animated title.
- [ ] HP bars animate smoothly when damaged/healed.
- [ ] Screen transitions have fade effects.
- [ ] DND_REDUCED_MOTION disables all animations.
