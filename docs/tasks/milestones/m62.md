
# Milestone 62 (M62) Plan

## Overview
Milestone 62 focuses on the following objectives:

1. **Enhance Visual Testing Coverage**
	- Expand and refine visual scenarios in `tests/visual_scenarios.json`.
	- Ensure all new features and bug fixes are visually validated.
2. **Gameplay Balancing**
	- Adjust item, monster, and spell stats for improved game balance.
	- Update relevant TOML files in `assets/`.
3. **Performance Improvements**
	- Profile and optimize game startup and rendering.
	- Address any bottlenecks identified in `src/renderer.rs` and `src/main.rs`.
4. **Documentation Updates**
	- Update `docs/ENGINE_RULES.md` and `docs/DOCS_MAP.md` to reflect changes.
	- Ensure all new/modified features are documented.
5. **Automated Validation**
	- Run `scripts/visual_check.py` and validate outputs in `test_outputs/`.
