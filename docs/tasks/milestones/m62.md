## Bug 1 — HP label is duplicated (`HP Theron HP ...` / `HP HP ...`)

- Repro:
  - `python3 scripts/visual_check.py --scenario enter_world --show --artifact none`
  - `python3 scripts/visual_check.py --scenario open_inventory --show --artifact none`
- Observed:
  - Health line prints duplicated text (for example `HP Theron HP ...` and `HP HP ...`).
- Caused files:
  - `src/ui/tui/theme/icons.rs`
  - `src/ui/tui/screens/world_map.rs`
  - `src/ui/tui/screens/inventory.rs`
- Fix approach:
  - Use either the health icon token or the literal `HP` label, not both.
  - Keep T0/T1 fallback clean (`HP`) and avoid rendering an extra `HP` span in screen code.

## Bug 2 — World controls footer truncates key hints when feedback is shown

- Repro:
  - `python3 scripts/visual_check.py --scenario enter_world --artifact none`
  - `python3 scripts/visual_check.py --scenario move_around --show --artifact none`
- Observed:
  - After a feedback message appears (ash coughing), last control hints are clipped; lines like `p save / o load / b toggle sound / q quit` disappear.
- Caused files:
  - `src/ui/tui/screens/world_map.rs`
- Fix approach:
  - Increase footer area height or reduce line count dynamically.
  - Ensure `footer_lines.len()` always fits within the content area of `chunks[3]`.

## Bug 3 — Visual test scenarios do not match their descriptions (false-positive playtests)

- Repro:
  - `python3 scripts/visual_check.py --scenario tidewatch_start --show --artifact none`
  - `python3 scripts/visual_check.py --scenario volcanic_curse_quest --show --artifact none`
  - `python3 scripts/visual_check.py --scenario underdark_shelf --show --artifact none`
- Observed:
  - Scenarios claim deep progression states but only execute short key sequences that stop at character creation or the initial Valley of Ash room.
- Caused files:
  - `tests/visual_scenarios.json`
  - `scripts/visual_check.py` (scenario runner currently trusts key macros only; no end-state assertions)
- Fix approach:
  - Replace placeholder key macros with full deterministic paths (or seed setup shortcuts).
  - Add scenario assertions in `visual_check` (expected app state/region/room) so mismatches fail explicitly.
