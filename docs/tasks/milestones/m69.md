# Milestone 69 — Procedural Content Layer (Landmarks, Encounters, Loot, Hazards)

**Goal:** Make generated maps unique and gameplay-rich.

**Status:** 🔲 PLANNED

## Scope
- Landmark generator: at least one unique landmark per generated map.
- Encounter placement weighted by biome + danger tier.
- Loot placement weighted by rarity + route depth.
- Hazard placement with path safety guarantees.

## Constraints
- Minimum interactables per generated map.
- At least one low-risk traversal path from entry to exit.

## Done when
- [ ] Every generated map has landmark + interaction opportunities.
- [ ] Encounter/loot/hazard distributions pass configured validator thresholds.
- [ ] Visual dumps show diversity across seeds.
