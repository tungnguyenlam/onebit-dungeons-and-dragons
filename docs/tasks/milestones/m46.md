# M46 — Rich Widget Library

**Status:** 🔲 planned
**Depends on:** M44

---

## Goal

Build a collection of reusable, styled widgets for common UI patterns to improve consistency and reduce screen-specific code.

---

## Scope

- **Progress Bars**: Reusable HP, XP, and resource bars with labels.
- **Stat Blocks**: Styled character stat displays (ability scores, saving throws).
- **Item Cards**: Rich item display with icons, stats, and tooltips.
- **Dialog Bubbles**: Styled NPC speech and player choices.
- **Lists**: Paginated inventory, spellbook, and journal lists.

---

## Target Files

- `src/ui/tui/widgets/` (New): Widget module.
- `src/ui/tui/widgets/progress.rs`: Progress bar widgets.
- `src/ui/tui/widgets/items.rs`: Item display widgets.
- `src/ui/tui/widgets/lists.rs`: List widgets.

---

## Done When

- [ ] At least 5 reusable widgets created.
- [ ] All screens use shared widgets where applicable.
- [ ] Widgets support theming and accessibility.
