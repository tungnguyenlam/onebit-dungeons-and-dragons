# M44 — Enhanced TUI Color System

**Status:** ✅ completed
**Depends on:** M40

---

## Goal

Expand the TUI's color palette with truecolor support, semantic coloring for game elements, and improved accessibility contrast.

---

## Scope

- **Semantic Colors**: Define consistent colors for health (green→red), mana (blue), enemies (red), allies (green), items (gold).
- **Truecolor Gradients**: Use 24-bit colors for HP bars, mana bars, and environmental effects.
- **Color Themes**: Support multiple color schemes (dark, light, high-contrast).
- **Accessibility**: Ensure minimum contrast ratios for readability.

---

## Target Files

- `src/ui/tui/theme.rs`: Extended color definitions with semantic colors and themes.
- Added health_full/medium/low, mana, xp, player, enemy, npc, item, quest_active/complete, connection, wall, floor colors.
- Added ColorTheme enum with Dark, Light, HighContrast themes.
- Added helper functions: health_color, mana_color, xp_color, gradient_color, color_blind_mode.

---

## Done When

- [x] All game elements use semantic colors.
- [x] Truecolor gradients render on supported terminals.
- [x] Theme switching works without restart (DND_THEME env var).
- [x] High-contrast mode passes WCAG AA.
