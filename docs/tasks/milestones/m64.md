# Milestone 64 — Edge-Based Room Transitions

**Goal:** Replace door-centric room traversal with smoother movement by allowing room transitions from map edges, while preserving trigger-based travel for special routes.

**Status:** ✅ COMPLETED

3. Existing `travel` trigger behavior remains for conditioned and inter-region transitions.
4. Added flow tests for step-trigger and edge-transition room travel.
5. Updated world/map docs to describe the new traversal behavior.
