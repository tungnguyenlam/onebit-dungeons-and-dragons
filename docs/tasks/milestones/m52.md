# Milestone 52 — Flee Mechanics & Combat AI Targeting

**Goal:** Provide players with an escape mechanism from unwinnable encounters and ensure enemy AI logic is fair by utilizing pseudorandom targeting when appropriate.

**Design:**
1. **Flee Action:** Add a new action "Flee" bound to `f` or `4` in combat. When chosen, the player makes an opposed Dexterity check against the highest Dexterity enemy currently alive. On success, the battle ends instantly and the player returns to the World Map. On failure, the player's turn is consumed with a log message "Flee failed!".
2. **AI Target Selection:** Fix `select_enemy_target` such that if `prefer_low_hp` is false, the enemy selects a pseudorandom target among available valid targets using the `ctx.seed` rather than always picking the first target (which unfairly focuses the first ally sequentially).

**Files to modify:**
- `src/renderer.rs` (add Flee event mapping if needed, or just use Choice(4))
- `src/app/handlers.rs` (combat event dispatcher)
- `src/app/combat.rs` (implement `try_flee` and update `select_enemy_target`)
- `src/ui/tui/screens/combat.rs` (update combat controls footer)
- `scripts/visual_check.py` or `.json` to include a test scenario for fleeing.

**Done when:**
- [x] Attempting to Flee succeeds or fails based on Dex checks.
- [x] AI enemy picks targets pseudorandomly.
- [x] Visual checks can run the flee command in combat without crashing.
