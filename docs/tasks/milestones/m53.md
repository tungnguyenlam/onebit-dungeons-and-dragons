# Milestone 53 — Advanced Character Specialization (Feats & Multiclassing)

**Goal:** Implement the foundation for D&D 5e Feats and allow characters to spend ability score improvements on them, plus enable basic multiclassing logic for level-ups.

**Design:**
1. **Feat Registry:** Create a new registry in `src/game/character/feats.rs` and matching TOML assets in `assets/feats/`.
2. **Ability Score Improvement (ASI) Choice:** Update the leveling logic in `src/app/progression.rs` to allow choosing a Feat instead of +2 ASI when reaching appropriate levels (4, 8, etc.).
3. **Multiclassing Base:** Update `CharacterState` and `CharacterDef` to support a list of classes and levels (e.g., `Fighter 3 / Wizard 1`) rather than a single `class_id`.
4. **Prerequisite Verification:** Implement checks for multiclassing (e.g., Min Strength 13 for Paladin) based on SRD rules.

**Files to modify:**
- `src/data/types.rs` (update `CharacterDef` and add `FeatDef`)
- `src/game/character/mod.rs` (link new feat logic)
- `src/game/character/stats.rs` (update `Character` struct for multi-class support)
- `src/app/progression.rs` (handle level-up logic for ASI/Feats and multiclassing)
- `src/ui/tui/screens/character_creation.rs` (UI for selection)

**Done when:**
- [ ] Players can select a Feat during level-up.
- [ ] At least 3 sample Feats (e.g., Tough, Great Weapon Master, Magic Initiate) are functional.
- [ ] Characters can add a second class during level-up if they meet prerequisites.
- [ ] Proficiency bonuses and HP correctly calculate across combined levels.
