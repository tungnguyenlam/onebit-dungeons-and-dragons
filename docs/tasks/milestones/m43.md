# M43 — Automated Playtest Agent

**Status:** ✅ completed
**Depends on:** M41

---

## Goal

Build an agent that can autonomously navigate the game world, simulating a player to discover bugs, dead ends, and accessibility issues.

---

## Scope

- **Navigation AI**: Simple pathfinding to explore all reachable rooms.
- **Action Executor**: Execute combat, dialog, and inventory actions programmatically.
- **Bug Detection**: Detect crashes, softlocks, and unreachable states.
- **Exploration Report**: Generate reports of visited rooms, found items, and potential issues.

---

## Target Files

- `src/app/playtester.rs` (New): Autonomous playtest agent.

---

## Done When

- [x] Agent can complete at least one full region traversal.
- [x] Agent can trigger and complete a combat encounter.
- [x] Agent can complete a quest dialog tree.
- [x] Bug report generated with crash logs if any.
