# Interactive Playtest Checklist

This checklist is for manual and automated interactive playtest sessions using scenario-aware runner presets and deterministic capture mode.

## Checklist

- [ ] Select scenario preset (`ash_gate`, `ember_square`, `river_watch`)
- [ ] Run with `--interactive` for manual playtest
- [ ] Run with `--capture` and `--token-efficient` for deterministic artifact
- [ ] Limit frames/events with `--max-frames <N>`
- [ ] Save compact summary and key event snapshots
- [ ] Review output for UI/readability/animation findings
- [ ] Complete a full escape run for `ash_gate` scenario
- [ ] Attach before/after evidence for any UX changes
