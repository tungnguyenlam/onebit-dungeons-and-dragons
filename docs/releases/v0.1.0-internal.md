# v0.1.0-internal Release Notes (2026-02-20)

## Scope

This internal release completes milestones M0-M13:
- core systems, combat, story/dialog, items/spells, NPC/faction behavior
- three authored regions with reusable content pipeline
- save/load hardening with explicit format versioning
- TUI capability tiers, semantic theme tokens, and icon fallbacks

## Key Changes

- Save format now includes `format_version = 1` and accepts legacy saves that lack this field.
- Content pipeline includes templates and validation helpers:
  - `docs/content/regions/templates/*`
  - `scripts/validate_content.sh`
- Release validation command:
  - `scripts/release_check.sh`

## Compatibility

- Save compatibility: legacy saves without `format_version` are treated as version `1`.
- Terminal visual tiers:
  - `T0` ASCII fallback
  - `T1` UTF-8 glyphs
  - `T2` 256-color palette
  - `T3` truecolor palette

## Verification Summary

- `cargo test` passes.
- content validation passes.
- startup/data-load profile smoke test passes.

## Handoff Notes

- GUI renderer remains intentionally stubbed.
- Warning-only cleanup remains out of scope unless explicitly requested.
- Next work should be post-release triage/perf regression tracking and content expansion.
